# tgpinbot

Ты прав: в прошлых коммитах была навязана лишняя логика. В этом коммите оставлен только нейтральный каркас Telegram-бота без выдуманных фич.

## Что теперь в репозитории

- Базовый запуск Telegram-бота
- Подписка/отписка пользователей на уведомления
- Тестовое уведомление
- Админская рассылка
- Без Pinterest-скачиваний и без лишней самодеятельности

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# заполни TELEGRAM_BOT_TOKEN и ADMIN_CHAT_IDS
python bot.py
```

## Команды

- `/start`
- `/help`
- `/subscribe`
- `/unsubscribe`
- `/notify_now`
- `/broadcast <текст>` (только ADMIN_CHAT_IDS)
